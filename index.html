index.html — обложка (фронтенд, как в HTML-играх). ai_chat.py — мозги и чат. Кнопка ниже связывает их: ведёт на Gradio на этом же ПК.

Открыть чат-помощник

Сначала нажми Run для ai_chat.py в PyCharm и дождись строки Running on local URL: http://127.0.0.1:7860. Потом жми кнопку.

Порядок запуска

  1. Run ai_chat.py (Python + Gradio).
  2. Открой index.html (двойной щелчок или Open in Browser).
  3. Кнопка «Открыть чат» → вкладка Gradio с Gemini.
🔐 Безопасность: API-ключ только в ai_chat.py, не в index.html. На GitHub Pages заливай только index.html (без .py с ключом). Кнопка на опубликованном сайте откроет чат только на том компьютере, где снова запущен ai_chat.py.
Локально: index.html и Python работают вместе · деплой — только HTML-обложка
